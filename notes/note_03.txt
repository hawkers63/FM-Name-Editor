## 1. Executive Summary & Diagnostic Audit

An exhaustive technical investigation of the **FM Name Editor** application and the underlying **Football Manager 27** database directory has been conducted. The current implementation demonstrates exceptional baseline engineering: it reads and writes 16,448 records in ~0.25 seconds with an RSS memory footprint of under 29 MB, strictly enforces byte-for-byte preservation for untouched lines, respects the UTF-8 Byte-Order Mark (BOM), and retains native line endings (`\r\n`).

However, the application is currently constrained by two major factors:
1. **Plain, Monolithic Interface:** The graphical interface relies on default operating system Qt widgets arranged in a single flat table. It displays long names, short names, and three-letter codes on disconnected rows, forcing repetitive hunting and editing rather than presenting a unified club or competition entity.
2. **Untapped Game Integration & Workflow Capabilities:** The application operates in complete isolation from the Football Manager installation. Users must manually browse deep file paths (`D:\Steam\steamapps\common\Football Manager 27\...`) to locate `.lnc` files, lack automated batch renaming or formatting tools, have no one-click deployment or backup rollback mechanisms, and miss crucial game licensing interactions (such as the DBC/EDT files that override name edits in-game).

## 3. Technical Defect Remediation (Review Note 02 Audit)

Before introducing interface enhancements, seven identified edge-case defects from [note_02.txt](file:///c:/FM%20Name%20Editor/notes/note_02.txt) require surgical resolution to guarantee software stability:

1. **B1 — Atomic Serialisation on Save:** Currently, `LncDoc.save()` copies a timestamped backup before verifying that the payload can be encoded in `self.encoding`. If a character cannot be represented in the chosen code page, `UnicodeEncodeError` is raised, escaping the `OSError` handler in `MainWindow.save` and leaving an unnecessary backup.  
   *Resolution:* Build `self.to_bytes()` first; execute `shutil.copy2` only upon successful byte generation; broaden GUI exception handling to `except (OSError, UnicodeError):`.
2. **B2 — Control Character Sanitisation (`name_is_legal`):** In `EntryModel.setData`, empty strings and quotes are blocked, but newline (`\n`), carriage return (`\r`), and ASCII control characters are accepted, which corrupts the record structure on subsequent reloads.  
   *Resolution:* Implement `name_is_legal(new)` enforcing non-emptiness, lack of double quotes, and restricting characters to `ord(c) >= 32` or tab (`\t`).
3. **B3 — Skipped Entry Auditing & Import Pre-Tick Safety:** `build_proposals` silently drops older names containing quotes or empty values without notifying the user, and pre-ticks rows where the stock name was updated between FM24 and FM27 (`note == 'Renamed since'`).  
   *Resolution:* Track a `skipped` count in `stats` and present it in the dialog summary; default `pre_tick = (base is not None and note != 'Renamed since')` so stock updates are not inadvertently overwritten.
4. **B4 — Multi-Row Duplicate Key Resolution:** When multiple rows share the same key `(cmd, id, lang)`, dictionary indexing causes only the last row to update during an import.  
   *Resolution:* Implement `index_all(docs) -> dict[tuple, list[Entry]]` so that all matching rows for an ID are synchronised together.
5. **B5 — Type Filter Dynamic Invalidation:** The type combobox fails to refresh when an import introduces a new command category.  
   *Resolution:* Encapsulate combobox population into `rebuild_type_filter()` and invoke it following both `load()` and `import_old()`.
6. **B6 — Revert Feedback Precision:** `revert_selected()` silently ignores newly imported additions without explaining why `orig_name` was not restored.  
   *Resolution:* Track both modified renames and skipped additions, reporting: `Reverted X name(s). Left Y added row(s) unchanged.`
7. **B7 — Environment-Agnostic Launcher:** `FM Name Editor.bat` hardcodes a specific Python 3.11 path.  
   *Resolution:* Check `where python` on the system `PATH` first, falling back to the local installation only if needed.

#### Mode A: The Entity View (Unified Club & Competition Editor)
This fulfils Mark's original specification from [note_01.txt](file:///c:/FM%20Name%20Editor/notes/note_01.txt):
* Rather than navigating three disjointed rows for a single club, the **Entity View** aggregates records by ID.
* For Clubs: Displays `Country`, `ID`, `Long Name`, `Short Name`, `3-Letter Code`, and `Status` side-by-side.
* For Competitions: Displays `Country`, `ID`, `Long Name`, `Short Name`, `6-Letter Code`, and `Status`.
* Editing the short name or 3-letter code happens within the same table row or the side Inspector. Behind the scenes, the engine updates the exact respective `CLUB_NAME_CHANGE`, `CLUB_SHORT_NAME_CHANGE`, or `CLUB_3LETTER_NAME_CHANGE` entries in the underlying `.lnc` file.

#### Mode B: The Line View (Classic Raw Table)
* Retains the granular, line-by-line 16,448-row table for advanced users who require exact command-level inspection.

### 4.3. Navigation & Ergonomic Features
* **Collapsible Country & Section Sidebar:** A left-hand navigation tree listing countries with record counts (e.g., *England [543]*, *Spain [745]*, *Italy [640]*). Clicking a country instantly filters the central grid without typing.
* **Quick-Filter Status Chips:** One-click filter pills: `[All]`, `[Edited Only]`, `[Clubs]`, `[Competitions]`, `[Missing Short Name]`, `[Missing 3-Letter Code]`.
* **Collapsible Entity Inspector Panel:** A right-hand card displaying all details of the currently selected club or competition, with quick-action buttons (e.g., Capitalisation, Revert, Copy ID).
* **Live Workspace Metric Bar:** A top status strip displaying real-time counts: Total Entities, Loaded Files, Active Game Database, and Unsaved Edits.

## 5. Strategic & Innovative Feature Extensions

To transition the software from a simple text modifier to an indispensable tool for Football Manager customisation, five high-impact innovations are proposed:

### Innovation 1: Auto-Detect Game Environment & One-Click Deploy
* **Direct Game Integration:** The software automatically verifies `D:\Steam\steamapps\common\Football Manager 27\shared\data\database\db`, identifies available database folders (`2700`, future patch versions like `2730`), and detects installed `.lnc` files.
* **Quick-Load Button:** Opens the active database files immediately without requiring manual navigation through the file explorer.
* **One-Click Deploy to Game:** A dedicated "Deploy to FM27" action that validates, creates an automated timestamped backup in a dedicated archive folder, and saves directly to the game directory.

### Innovation 2: Licensing & Realism Health Inspector
* In Football Manager, `.lnc` files can be overridden if certain licensing blocker files remain in the game's DBC and EDT folders.
* The application incorporates an **FM27 Licensing Inspector** modal that scans:
  * `db\2700\dbc\permanent\Licensing2.dbc` (Blocks Juventus, Brazilian club names)
  * `db\2700\edt\permanent\fake.edt` (Blocks German and Japanese national teams)
  * `db\2700\dbc\permanent\japan_fake.dbc` & `brazil_kits.dbc`
* Provides a safe, one-click toggle to disable these blockers (by safely renaming them with a `.disabled` extension) or restore them, ensuring that user `.lnc` edits take full effect in-game without requiring external tools.

### Innovation 3: Bulk Naming Transformation Suite
Manual entry for hundreds of clubs across different leagues is laborious. The **Bulk Transformer** provides rule-based automation:
1. **Club Affix Stripper / Formatter:**
   * Strip or standardise prefixes/suffixes: `FC`, `CF`, `FK`, `SK`, `AC`, `AS`, `AFC`, `Calcio`.
2. **Competition Sponsor Cleanser:**
   * Automatically strips commercial naming rights from leagues (e.g. converting `"Sky Bet Championship"` to `"Championship"`, `"Barclays Women's Super League"` to `"Women's Super League"`).
3. **Casing Normaliser:**
   * Converts all-caps entries (e.g. `PARIS SAINT-GERMAIN` or `ATHLETIC CLUB`) to clean Title Case.
4. **Scoped Find & Replace:**
   * Search and replace strings with regex support, filterable by country or competition tier, featuring a live before-and-after diff preview.

### Innovation 4: Name Pack Export & Sharing (CSV / JSON)
* Allows exporting personal name configurations into clean, lightweight `.json` or `.csv` files.
* Enables importing community naming packs or transferring preferences between major Football Manager releases without requiring manual `.lnc` merging.

### Innovation 5: Backup & Rollback Archive Manager
* Instead of cluttering the game directory with unmanaged `.bak-<timestamp>` files, the application maintains a structured backup catalogue.
* Users can view a visual timeline of previous revisions, inspect differences against the current working state, and roll back with a single click.
