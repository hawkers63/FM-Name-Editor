I am contemplating the development of a new application. As an enthusiastic follower of the Football Manager series, having dedicated over 2,200 hours to version 24, I have been eagerly anticipating the release of Football Manager 27. I thoroughly enjoyed the pre-release version and have since acquired the Steam edition, which I am currently exploring.

One feature that I particularly value is the ability to customise the spellings of competitions and team names according to my preferences. FM Scout has provided a .inc file that facilitates this customisation. I have created a significantly modified .inc file for Football Manager 24 and wish to adapt it for use with the 27 version.

My objective is to develop an application using Python that will extract information from the .inc file and present it through a user-friendly interface for name modifications. Ultimately, this application will prepare the file for in-game integration.

The files consist of plain UTF-8 text, with each line containing a singular instruction, which enhances usability.

### Contents of the Files
| File                     | Lines  | Main Contents                                                                 |
|--------------------------|--------|-------------------------------------------------------------------------------|
| FM27_Club_Names.lnc     | 8,935  | 4,078 club long names, 4,298 short names, 242 three-letter codes            |
| FM27_Fix.lnc            | 9,092  | 3,741 competition long names, 3,778 short names, 272 stadiums, and additional data including awards, cities, player names, and national team corrections |

Each line adheres to a consistent format: a command, a database ID, and the new name. For instance, a line may appear as: `"CLUB_NAME_CHANGE" 58 "KF Apolonia" ""`. Lines commencing with a # serve as comments and also function as country headings (e.g., #Albania, #England), which will assist in the grouping mechanism of the application.

### Proposed Functionality of the Application
1. **Parsing**: Each line will be read into a record comprising the command, ID, name, and language, while preserving comments and blank lines to ensure no information is lost.
2. **Browsing and Editing**: The application will present a searchable table, organised by country, displaying long names, short names, and three-letter codes side by side for each club, as they share the same ID.
3. **Saving**: The modified data will be written back to the file in the exact format required by the game, with a backup of the original file created beforehand.

### Key Considerations
- **Inconsistent Spacing**: The files utilise a combination of tabs and spaces between fields; therefore, the parser must accurately read quoted strings rather than separating them based on tabs.
- **Diverse Line Structures**: Player names comprise three components, national team entries contain only numbers, and awards include a language specification, such as "English".
- **Accented Characters and BOM**: Names such as Kukësi and Skënderbeu must be preserved throughout the process, and the file begins with a byte-order mark that must be maintained.
- **Unrecognised Lines**: Any lines that the parser does not identify should remain unchanged rather than being discarded.

### Features of Version 1.0
- **Browse and Search**: Opens both FM27 files in a unified table of 16,448 names, featuring accent-insensitive search functionality (e.g., searching for “skenderbeu” will yield results for Skënderbeu) and a filter by type.
- **Edit**: Users can double-click a name to modify it; edited rows will be highlighted in bold and can be reverted if necessary.
- **Import Older Edits**: Compares my FM24 files against FM27 by ID, displaying a checklist of current names alongside my modified names, which can be filtered by country or club.
- **Save**: Initially writes a timestamped .bak backup, and lines that remain untouched will be written back byte-for-byte.
